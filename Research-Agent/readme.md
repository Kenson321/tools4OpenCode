真正有价值的 PTR Agent 应该具备三个能力：

第一，知道研究什么。

例如，每个月研究银行科技动态时，它应该能根据研究主题制定研究计划，确定重点技术方向、信息来源和检索关键词。

第二，知道哪些资料值得读。

不能搜索到100篇文章就总结100篇。它需要判断资料的可信度、时效性、技术价值和重复程度，并给出筛选理由。

第三，知道什么时候需要更强的模型。

本地14B模型完成基础工作后，将筛选后的资料、原文证据和分析结果交给更强的模型，完成趋势判断、行业影响分析和最终报告。
